## 🧱 확정 기술 스택 (TSD §2 요약)

| 레이어 | 확정안 |

| 프론트엔드 | **Next.js 15 (App Router) · React 19 · TypeScript** |
| 스타일링 | **Tailwind CSS v4 + shadcn/ui** |

| 신청 경로 B | 다운로드 라우트 + 이메일 안내 카드 |
