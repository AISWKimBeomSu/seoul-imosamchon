# seoul.imosamchon

**서울 이모삼촌** — 시니어(5060+) 모집 브랜드 웹사이트

인스타·카톡·맘카페 등 멀티채널 모집 포스터의 클릭을 **브랜드 신뢰 + 실제 신청 완료**로 전환하는 허브입니다. SDD(명세 주도 개발) 방식으로 진행합니다.

## 기술 스택

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 + shadcn/ui · Supabase(Postgres+Storage+Auth) · Vercel
